An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in the author's own words that cites its sources, a saved checklist with filters and a spoiler setting, a four-stage roadmap to the platinum, and the four missable trophies flagged. The game had not released when this guide was written, so no specific in-game location or step is claimed beyond what the official trophy descriptions state. Static files only — no build step, no network requests at runtime.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a desktop browser. Or run `node main.ts` with `MAKEFUN_OUTPUT_DIR` set to build the submission output (app, screenshots and dossier.json).
